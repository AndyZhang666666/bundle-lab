# Bundle Lab：经营账本工作区精修

本轮在 `062b656` 发布版上改进操作与阅读，不变更 two-population-v2 模型、来源、存储键、冻结方案或验证计划。线上版保留，本分支用于联合本地审阅。

## 使用路径与决定

1. 从内置、手工或确认的 CSV 开始，商品始终可见。
2. 折扣和中档采纳放在主要输入区；人群、成本、领折扣率以可点击摘要呈现，展开的仍是原字段，关闭后不卸载草稿。
3. 数值编辑保留原始字符串。空值和越界值显示就地错误，阻止旧结果导出；React Aria 1.22.1 负责精确加减与可键盘操作的滑杆，二者写入同一个原假设值。数字输入没有使用会在失焦时自动修正数值的行为。
4. 结果使用模型实际输出组织成贡献、让利和净增量。桥接图只将这些金额转成屏幕坐标，不重新算收益。
5. 折扣×采纳矩阵明确列、行数量。黑框为当前输入，圆点为预演；取消、采用和直接存入比较仍调用原确认函数，预演不会静默改草稿。
6. A/B/C 显示冻结输入标签，分别对齐折扣、采纳、人群/成本/领折扣、账目和平衡点。当前草稿与选择、快照、验证计划各自独立。

## 视觉决定

使用原有纸色、墨绿和红褐。左边像输入单，右边像经过核对的账本：固定数值列、同口径的每100覆盖单、清楚的等式。辅助说明收起但始终可到达，不把不确定假设装成观测事实。

操作触达44px；面板原生展开，数字与图形立即更新。按压与焦点仅用短反馈，减少动态效果时关闭位移。手机纵向完成任务，长比较表和矩阵只在自己的容器滚动。
