# 产品与工程取舍

## 先修决策口径，再增加交互

本轮复现旧收益与平衡公式不一致：全体平均原花费不等于未买齐者原花费，未买齐采纳也不等于老顾客领折扣。使用两类人群共同公式，让账本、图表、平衡点、排序和导出同源。未买齐采纳为零仍可能有老顾客让利损失。

## 一套假设贯穿完整流程

组合发现可把全部订单候选带到收益推演。推演输入存本机并校验恢复；建议页使用同组输入重新评估全部候选，避免看完改过的模拟却导出默认建议。分群候选不直接带入全量推演，明确口径差异。

比较最多三个，可增删并允许空清单；全清空不损失参数。规则建议只推荐当前中档毛利为正且满足覆盖/去重的组合，允许没有推荐。覆盖重叠使收益不可加总，不把去重视为蚕食模型。

## 输出一份可以继续工作的假设

JSON含模型版本、输入与分人群结果；Markdown和结构化建议同时包含验证计划。实验计划要求按用户分流、区分已买齐/未买齐者、核查曝光与采纳，主指标和护栏由实际业务确定，不伪造样本量或阈值。

## 模型只能产生未核对草稿

同一JSON提示不能保证模型不改数字。保留可选润色，正式导出永远为规则版；模型草稿分开标记、单独下载。Key仅页面内存，清除旧版持久化记录；手动请求、取消、30秒超时及失败回退，输入或连接变化作废旧润色，不自动消耗额度。

## 保留技术与数据，调整操作层级

沿用Next、原生CSS、Apriori、六页与内置订单。原红色用在数据，导航和主按钮归墨色；修窄屏导航、字体对比度、表格内部滚动和键盘展开。桌面左假设右账本；手机顶部先给一条同源结果，再调输入，长公式和选组清单按需展开。

## 校验能证明什么

手算证明特定公式实现与预期一致；固定合成召回描述此样本，不证明市场规律。“2000单可用”“高命中必做加价购”“模型数字一定不变”等旧表述本轮撤下。旧模型的LLM样本保留为历史，不作当前效果证据。未进行真实促销、真人研究或完整无障碍认证。
