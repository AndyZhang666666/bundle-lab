# 假设、口径与局限

当前模型 two-population-v2-2026-10-25。以下输入均未经真实业务校准，不使用“行业通行值”给演示参数背书。

## 订单与组合

内置4000笔合成订单、32个SKU，固定种子20260913。按每SKU一件建模；份量、数量和后续购买均未建模。被覆盖订单至少含一件，命中订单含全部。历史整套订单的人群与时段分布不等于适合促销的对象。

关联阈值默认支持度1%、置信度10%、lift1.2；这是演示筛选值。lift未提供显著性或区间，组合排名是启发式排序。固定合成样本的召回/样本阶梯不能推广为真实业务最低订单量。

## 两类人群收益

L为组合原价，B为折后价，P为覆盖订单在这些商品上的平均原花费。h为其中原本已买齐的比例，r为这类人领折扣的假设比例，a为未买齐者的采纳假设，c为食材成本率。

```text
S部分 = (P − hL) / (1 − h)
g = B − cL − S部分(1 − c)
新增毛利贡献 = (1 − h)ag
既有顾客让利损失 = hr(L − B)
每覆盖单 Δ毛利 = 新增贡献 − 既有损失
```

套餐外商品保持不变。所有金额是同一覆盖订单口径；比较不同组合时按 Δ毛利乘覆盖数排序，但订单有重叠，不能相加。成本仅包含统一比例的食材成本，不是净利润。

平衡点使用同一公式；分母不为正、所需采纳率超过100%、全部已买齐、零损失与零增量分别处理。中档毛利不为正的组合不进入推荐。

## 默认值

折扣12%、成本40%、未买齐者采纳低/中/高5%/12%/25%、既有整套者领折扣100%，均为作者构造的输入。各概率支持0到100%，三档保持不减，不是置信区间。改变价格不会自动改变采纳率；r与a独立控制。

建议覆盖至少100单、商品重合超过50%去重，也是演示规则。不能证明一定能覆盖运营成本或不存在订单蚕食。

## 局限

没有价格弹性、曝光选择、履约与退款费用、库存、份量变化、跨订单蚕食或真实实验数据。未知因素不保证只向乐观方向偏移，因此不称输出为严格上界。应先定义实验单位、基线、护栏、样本和停止条件，再验证。
