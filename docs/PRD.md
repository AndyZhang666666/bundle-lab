# Bundle Lab 产品范围 · 2026-10-25

## 用户与任务

面向理解订单表、需要判断是否值得尝试套餐的运营人员。当前是内置合成数据的可操作演示，目标是把观察、收益假设、风险与验证下一步串起来，不接真实交易。

## 流程与产出

- 订单画像：结构信号及可能解释，不据此认定流失。
- 组合发现：分群、阈值、排序、键盘展开关联方向；全量候选可带入模拟，分群候选明确全量口径差异。
- 收益推演：两类人群账本、低/中/高情景、共同平衡点、最多三组比较、草稿与JSON导出。
- 建议：沿用当前假设重算全部候选，展示入选/未入选与去重原因，导出带实验计划的规则Markdown和结构化依据。
- 校验：原有手算、固定合成召回和阶梯结果；收益侧增加独立手算与边界检查。
- 方法：完整公式、默认值与未建模因素。

## 状态要求

非法概率、金额与不一致的人群统计拒绝估算；无覆盖订单拒绝虚构收益。零采纳、零成本、全折扣和全已买齐有可解释结果；无正向推荐、空对比清单、损坏/禁用存储可恢复。输入改变即时重算，不复用旧结论。

可选模型无Key亦不影响主流程；不自动请求，Key不持久化。取消/失败/超时保留规则输出；润色草稿不取代正式导出。

## 完成标准与边界

保留原21项手算，新增两类人群、平衡点、零值、草稿与报告一致性检查；生产静态构建；真实Chrome走完整链路及六路由四宽度、键盘、减少动画、存储恢复和模拟模型响应。逐项实测状态见VALIDATION，不能把尚未运行的项目写成通过。

没有CSV上传、平台接口、真实业务实验、显著性、价格弹性、库存、份量变化或订单蚕食模型。未拿固定合成样本推断真实最低样本量，未新增实际收益/采纳成绩。
